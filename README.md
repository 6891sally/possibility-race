# 🏁 가능성 레이스

5학년 2학기 수학 6단원 「평균과 가능성」 **5~7차시**(일이 일어날 가능성을 말로·비교·수로) 복습용 **실시간 개인전 퀴즈 웹앱**입니다.

- 학생: 1인 1태블릿(갤럭시탭 S6 Lite, 가로)으로 `play.html` 접속
- 교사: 교실 TV(1920×1080)에 `host.html` 띄우기
- 혼자 연습: `practice.html` (인터넷 연결만 되면 되고, Firebase가 필요 없음)

```
index.html          첫 화면 (실시간 레이스 참가 / 혼자 연습)
play.html           학생 레이스 화면
host.html           교사 화면 (비밀번호 0520)
practice.html       혼자 연습
test.html           자동 테스트 (문제 생성기·점수·아이템·QR)
qr.html             학생용 QR 코드 인쇄
js/qr.js            QR 코드 만들기
js/questions.js     문제 생성기 (레이스·연습 공용)
js/game.js          점수·순위·아이템 규칙
js/db.js            Firebase 연결 (설정이 비어 있으면 '체험 모드')
js/common.js        캐릭터·효과음·화면 그리기
js/firebase-config.js   ← 선생님이 Firebase 설정값을 붙여 넣는 곳
css/style.css
database.rules.json     ← Firebase 보안 규칙
```

## 0. 먼저 알아 두기

- **체험 모드**: `js/firebase-config.js`가 비어 있거나 주소 끝에 `?demo=1`을 붙이면(예: `host.html?demo=1`, `play.html?demo=1`), 같은 컴퓨터·같은 브라우저의 **탭끼리만** 연결되는 체험 모드로 동작합니다. 수업 전에 교사 화면 탭 1개 + 학생 화면 탭 여러 개를 열어 흐름을 미리 연습해 볼 수 있어요(실제 Firebase 방에는 영향 없음). 체험 모드 교사 화면의 QR에는 `demo=1`이 자동으로 붙어요.
- **비밀번호 0520은 '잠금' 수준**입니다. 비밀번호 확인을 브라우저(학생도 볼 수 있는 코드)에서 하므로 보안 장치가 아니라, 학생이 실수로 교사 화면에 들어오는 것을 막는 정도예요. 바꾸려면 `host.html`에서 `const PASSWORD = '0520';`을 고치세요.
- 점수 계산과 아이템 효과는 **교사 화면만** 합니다. 학생 화면은 "어떤 답을 골랐는지"와 "아이템을 쓰겠다는 의사"만 저장하고, 보안 규칙이 학생이 점수를 직접 고치지 못하게 막습니다.

## 1단계. Firebase 프로젝트 만들기 (처음 한 번만, 약 10분)

### 1-1. 프로젝트 만들기
1. https://console.firebase.google.com 에 구글 계정으로 로그인합니다.
2. **[프로젝트 추가]** → 프로젝트 이름(예: `possibility-race`) 입력 → 계속.
3. "Google 애널리틱스"는 **사용 안 함**으로 꺼도 됩니다 → **[프로젝트 만들기]**.

### 1-2. Realtime Database 만들기
1. 왼쪽 메뉴 **빌드 → Realtime Database** → **[데이터베이스 만들기]**.
2. 위치: **싱가포르(asia-southeast1)** 를 고르면 우리나라에서 빠릅니다.
3. 보안 규칙: **"잠금 모드로 시작"** 선택 → **[사용 설정]**.
4. 화면 위쪽에 보이는 주소(예: `https://possibility-race-default-rtdb.asia-southeast1.firebasedatabase.app`)가 **databaseURL** 이에요. 메모해 두세요.

### 1-3. 익명 로그인 켜기
1. 왼쪽 메뉴 **빌드 → Authentication** → **[시작하기]**.
2. **로그인 방법(Sign-in method)** 탭 → **익명(Anonymous)** → **사용 설정** 켜기 → **[저장]**.
   (학생은 아이디·비밀번호 없이 자동으로 '익명 사용자'가 됩니다. 같은 태블릿이면 새로고침해도 같은 사용자로 돌아와요.)

### 1-4. 보안 규칙 붙여 넣기
1. **Realtime Database → 규칙(Rules)** 탭을 엽니다.
2. 안에 있는 글을 모두 지우고, 이 폴더의 **`database.rules.json` 내용 전체**를 복사해 붙여 넣습니다.
3. **[게시]** 를 누릅니다.

규칙이 하는 일:
- 로그인(익명 포함)한 사람만 읽기
- 방의 상태·점수·아이템·알림은 **방을 만든 선생님(hostUid)만** 쓰기
- 학생은 **자기 자리**(`players/내uid`: 번호·이름·캐릭터)와 **자기 답**(`answers/문제/내uid`)만 쓰기
- 답은 **한 번만** 쓸 수 있고, 문제가 진행 중일 때만, 서버 시각(`answeredAt`)으로만 저장
- 24시간이 지난 방은 누구나(=다음에 방을 만드는 선생님 화면이) 지울 수 있음 → 새 방을 만들 때 자동 정리

### 1-5. 설정값을 `js/firebase-config.js`에 넣기
1. Firebase 콘솔 왼쪽 위 **톱니바퀴 → 프로젝트 설정** → **일반** 탭 아래 **"내 앱"** → **웹(</>)** 아이콘.
2. 앱 닉네임(예: `race-web`) 입력 → **[앱 등록]** (Firebase 호스팅 체크는 하지 않아도 됩니다).
3. 화면에 나오는 `const firebaseConfig = { ... }` 안의 값을 `js/firebase-config.js`의 같은 이름 칸에 그대로 붙여 넣습니다.

```js
export const firebaseConfig = {
  apiKey: "AIza....",
  authDomain: "possibility-race.firebaseapp.com",
  databaseURL: "https://possibility-race-default-rtdb.asia-southeast1.firebasedatabase.app",
  projectId: "possibility-race",
  storageBucket: "possibility-race.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef"
};
```
> `databaseURL`이 화면에 안 보이면 1-2의 4번에서 메모한 주소를 직접 넣으세요.
> 이 값들은 공개되어도 괜찮은 '주소' 같은 값이에요. 데이터 보호는 1-4의 보안 규칙이 합니다.

## 2단계. GitHub Pages로 배포하기

1. https://github.com 에 로그인 → 오른쪽 위 **+ → New repository**.
2. 이름(예: `possibility-race`) 입력, **Public** 선택 → **[Create repository]**.
3. 새 저장소 화면에서 **"uploading an existing file"** 링크 클릭.
4. 이 폴더 안의 **모든 파일과 폴더**(`index.html`, `play.html`, `host.html`, `practice.html`, `test.html`, `js` 폴더, `css` 폴더, `database.rules.json`, `README.md`)를 끌어다 놓습니다. → **[Commit changes]**.
   - 폴더째 끌어다 놓으면 `js/`, `css/` 구조가 그대로 올라갑니다. `.claude` 폴더가 보이면 올리지 않아도 돼요.
5. 저장소 **Settings → Pages** → **Source: Deploy from a branch**, **Branch: main / (root)** → **[Save]**.
6. 1~2분 뒤 위쪽에 주소가 나옵니다: `https://내아이디.github.io/possibility-race/`
7. 주소 뒤에 `test.html`을 붙여 열어 **"✅ 모두 통과"** 가 나오는지 확인하세요.

> 나중에 `firebase-config.js`만 고칠 때는 GitHub에서 그 파일을 열고 연필(✏️) 아이콘으로 편집 → Commit 하면 됩니다.
>
> ⚠️ **파일을 새로 올린 직후 10분 동안은 수업에 쓰지 마세요.** GitHub Pages가 파일을 최대 10분 동안 브라우저에 보관해서, 그사이에 연 태블릿은 옛 파일과 새 파일이 섞여 화면이 멈출 수 있어요. 10분 뒤에 열거나, 이상하면 태블릿에서 새로고침하세요. `test.html`이 "✅ 모두 통과"면 준비된 거예요.
>
> ⚠️ **결과 CSV처럼 학생 이름이 든 파일은 올리지 마세요.** 저장소가 공개라 누구나 볼 수 있어요.

## 3단계. 수업 진행 순서

### 수업 전 (TV 컴퓨터)
1. TV 컴퓨터에서 `https://내아이디.github.io/possibility-race/host.html` 을 엽니다. (전체 화면: F11)
2. 비밀번호 **0520** 입력.
3. 설정 고르기
   - 출제 범위: 5차시·6차시(기본) / 7차시까지 배웠다면 7차시도 체크
   - 문제 수: 5 / 10 / 15 / 20 (10문제면 약 10~12분)
   - 제한 시간: 10 / 15 / **20**(기본) / 30초
   - ✏️ 답 바꾸기: **허용**(기본) / 한 번만
   - 🏁 게임 방식: **개인전** / **모둠 대항전** (모둠 수 2~8, 모둠 정하기: 🎲 랜덤 뽑기 / ✋ 선생님이 지정)
   - 아이템 사용 켜기/끄기, 아이템별 켜기/끄기
4. **[방 만들기]** → TV에 4자리 **방 코드**와 QR이 크게 나옵니다.

### 학생 입장
1. 학생 태블릿에서 `https://내아이디.github.io/possibility-race/` → **[실시간 레이스 참가]**
   (또는 `.../play.html` 을 바로 열어도 됩니다. 패들렛이나 QR 코드로 미리 올려 두면 편해요.)
2. 방 코드 → 번호(1~30) → 이름 → 캐릭터 → **입장하기**
3. TV 대기실에 번호순 카드로 나타납니다. "○명 입장"을 확인하세요.
   - **같은 번호가 두 명**이면 빨간 카드와 경고가 뜹니다 → 잘못 들어온 카드의 **[내보내기]** → 그 학생 화면에 "다시 들어가기"가 나오면 번호를 바르게 다시 고르게 하세요.
   - 설정을 바꾸고 싶으면 대기실의 **[⚙️ 설정 바꾸기]**.
4. **모둠 대항전**이면
   - **🎲 랜덤 뽑기**: [🎲 랜덤 모둠 뽑기]를 누르면 인원 차이가 최대 1명이 되게 나눠요. 마음에 안 들면 [다시 뽑기]. 안 누르고 시작하면 자동으로 뽑아요.
   - **✋ 선생님이 지정**: 학생 카드 위의 모둠 표시(예: 🔴 1모둠)를 누를 때마다 다음 모둠으로 바뀌어요. 랜덤으로 뽑은 뒤 몇 명만 바꿔도 돼요.
   - 시작할 때 모둠이 없는 학생, 게임 중에 늦게 들어온 학생은 인원이 가장 적은 모둠으로 들어가요.
   - **모둠 점수 = 모둠원 점수의 평균**이라 모둠 인원이 달라도 공평해요.
5. 모두 들어오면 **[▶ 시작]**.

### 문제 진행 (선생님이 한 문제씩 넘김)
1. **문제 화면**: 문제·그림·보기, 타이머, "답한 학생 15/24" (누가 무엇을 골랐는지는 보이지 않아요)
2. **✏️ 답 바꾸기**(허용했을 때): 학생은 낸 뒤에도 [✏️ 답 바꾸기]로 시간 안에 몇 번이든 바꿀 수 있어요. **마지막 답과 마지막으로 낸 시각**으로 채점하니, 많이 바꿀수록 속도 보너스는 줄어요. 모두 답하면 3초 기다렸다가(그사이 바꿀 수 있게) 정답을 공개해요.
3. 시간이 끝나면 자동으로 **정답 공개**(해설 + 보기별 선택 인원 막대 + "답을 바꾼 학생 ○명(맞았다가 바꿔서 틀림 ○명)"). 더 빨리 넘기려면 [정답 공개 👀].
4. **[🏃 달리기 보기]** → 점수만큼 앞으로 달리는 트랙 애니메이션 (결승선 = 모두 만점일 때의 점수, 순위가 오르면 "추월!", 3연속 정답부터 🔥). 모둠 대항전은 **모둠 평균 점수**로 달리고, [👤 개인 보기]로 바꿔 볼 수 있어요.
5. **3문제마다 🎁 아이템 타임**: 학생마다 아이템 1개 (최대 5개 보유, 순위가 낮을수록 좋은 아이템이 잘 나와요). 학생들이 아이템을 쓰면 **[아이템 타임 끝내기]** → 🌪️돌풍·🎲주사위 결과가 TV와 태블릿에 나옵니다 → **[다음 문제]**.
6. 마지막 문제 전에는 **"🏁 결승 직전 스퍼트!"** (마지막 문제는 모두 점수 2배).
7. **🏆 시상식**: 1~3위 시상대(모둠 대항전은 모둠 시상대) + ⚡가장 빠른 손 + 🔥연속 정답왕 + 🚀역전의 주인공.
8. **📊 오답 복습**: 정답률이 낮은 문제 3개를 TV에 다시 띄워 함께 풀어요([👀 정답 보기] → [다음 ▶]). 학생 태블릿에는 "📺 지금 TV에서 ○번 문제를 다시 봐요 · 나는 ⭕/❌"가 나오고, **📝 내가 틀린 문제**를 눌러 내 답·정답·해설을 혼자 볼 수 있어요.
9. **CSV 내려받기**: 학생별(점수·정답 수·평균 응답 시간·답 바꾼 횟수·맞았다가 바꿔서 틀린 수·문항별 O/X), 문항별(정답률·답 바꾼 학생 수), 모둠별(모둠 대항전일 때: 평균 점수·모둠원).

조작 버튼: **⏸ 일시정지**(멈춘 시간은 응답 시간에서 빠짐) / **⏭ 문제 건너뛰기**(점수에 넣지 않음) / **🔄 게임 초기화**(점수 0, 학생은 대기실로).

### 문제가 생기면
- **학생 태블릿이 새로고침되거나 와이파이가 잠깐 끊겨도** 같은 태블릿이면 자동으로 같은 자리로 돌아옵니다.
- **교사 화면을 실수로 닫았으면** 다시 `host.html` → 0520 → **[↩ 방 ○○○○ 이어서 하기]**.

### 점수 규칙
| 상황 | 점수 |
|---|---|
| 정답 | 기본 100 + 속도 보너스 최대 50 (남은 시간 비율, 반올림) |
| 3연속 정답부터 | 🔥 +20 |
| 오답·미응답 | 0 (감점 없음) |
| 마지막 문제 | 모두 ×2 |
| 동점 | 평균 응답 시간이 빠른 학생이 위 |

응답 시간은 학생 기기 시계가 아니라 **서버 시각**(문제 시작 `startedAt` ↔ 학생 제출 `answeredAt`)으로 계산합니다.

| 🛡️ 연속 보호막 | 한 번 틀려도 🔥 연속 정답이 끊기지 않음 | 갖고만 있으면 자동 (연속 정답 중에 틀렸을 때) |
| 🎯 확신 카드 | 이번 문제를 맞히면 +50점, 틀려도 감점 없음 (카드만 사라짐) | 문제를 보고 나서 (문제 풀 때) |
| 🤝 응원 깃발 | 바로 뒤 순위 친구가 다음 문제를 맞히면 **나와 그 친구 모두 +30점** | 문제가 뜨기 전. 꼴등은 못 씀(받지도 않음) |
| 🎲 주사위 상자 | 굴려서 **짝수면 +40점, 홀수면 +10점** (짝수가 나올 가능성은 반반 = 1/2!) | 아이템 타임 |

모둠 대항전에서는 🌪️ 돌풍이 **같은 모둠 친구는 건너뛰고** 바로 앞의 다른 모둠 친구에게 불어요. 앞에 다른 모둠 친구가 없으면 다른 아이템으로 바뀌어요.

## 📷 학생용 QR 코드

- **교사 화면 대기실**에 QR 코드가 자동으로 나옵니다. 이 QR에는 방 코드가 들어 있어서, 학생이 태블릿 카메라로 찍으면 방 코드를 누르지 않고 바로 번호 고르기로 넘어가요.
- **인쇄용**: `https://내아이디.github.io/possibility-race/qr.html`
  - [🏃 실시간 레이스 참가] QR: 교실 벽이나 칠판에 붙여 두고 계속 쓸 수 있어요(방 코드는 학생이 직접 입력).
  - [📝 혼자 연습] QR: 범위(5차시 / 5~6차시 / 5~7차시)를 고르면 그 범위의 연습 링크 QR이 나와요.
  - 대기실의 **🖨️ QR 인쇄** 링크를 누르면 그 방 코드가 들어간 QR을 인쇄할 수 있어요.
- QR 생성은 외부 사이트 없이 `js/qr.js`가 직접 만들고, `test.html`이 만든 QR을 다시 읽어서 확인합니다.

## 4단계. 혼자 연습 링크 만들기 (패들렛 〈자투리 시간〉용)

주소 뒤에 `?range=` 로 범위를 붙입니다. 쉼표(,)로 차시를 이어 써요.

| 배운 범위 | 붙일 주소 |
|---|---|
| 5차시만 | `https://내아이디.github.io/possibility-race/practice.html?range=5` |
| 5~6차시 (기본) | `https://내아이디.github.io/possibility-race/practice.html?range=5,6` |
| 5~7차시 | `https://내아이디.github.io/possibility-race/practice.html?range=5,6,7` |
| 7차시만 | `https://내아이디.github.io/possibility-race/practice.html?range=7` |

- `?range=` 를 빼면 5~6차시로 나옵니다. 화면 위에 "범위: 5~6차시"처럼 표시돼요.
- 첫 화면 주소에 붙여도 됩니다: `.../index.html?range=5,6,7` → [혼자 연습] 버튼이 같은 범위를 그대로 넘겨요.
- 혼자 연습: 번호·이름 → 10문제 → 바로 정답과 해설 → 점수·별 3개 → **[틀린 문제 다시 풀기]**.
- 맞힌 문제 수가 태블릿에 쌓여 등급이 올라가요: 🌱 새싹 러너(0) → 🏃 달리기 선수(30) → 🏅 국가대표(80) → 👑 전설의 러너(150). (같은 태블릿·같은 번호와 이름 기준)

## 자동 테스트 (`test.html`)
- 범위 5 / 5,6 / 5,6,7 각각 생성기 1000회(1만 문제) → 범위 밖 문제 0개, **그림(SVG)에 실제로 그려진 개수·비율로 다시 계산한 정답**과 일치, 7차시 0·½·1 외의 수 0개
